# Step-by-Step Implementation Plan: Executive Portfolio Website

Roadmap for customizing, polishing, and deploying with **GitHub Copilot** or **Claude Code**.

---

## 📋 Milestones & Copilot Agent Prompts

### Step 1: Customize Candidate Data & Personal Branding
**Agent Prompt:**
> *"Update `src/data/portfolio_data.ts` with my specific university name, contact details, LinkedIn URL, GitHub profile, and custom domain name. Ensure all 4 flagship projects have verified repository links and live preview URLs."*

### Step 2: Build Interactive Polymer Sandbox Component
**Agent Prompt:**
> *"Enhance `src/components/LiveMaterialPlayground.tsx` with a dynamic multi-slider filter (Tensile Modulus, Density, Shore Hardness) and instant search over polymer trade names. Include visual badges for REACH compliance and automotive application tags."*

### Step 3: Implement Interactive Cloud Architecture Viewer
**Agent Prompt:**
> *"Build `src/components/ArchitectureViewer.tsx` using SVG or React Flow that lets recruiters toggle between 3 views: 1) AWS ECS Microservices Deployment, 2) LangGraph Multi-Agent SDS Swarm, 3) Enterprise AI FinOps Gateway. When clicking any node (e.g. Redis Cache), open a drawer displaying latency SLAs, security protocols, and cost impact."*

### Step 4: Configure Dark Mode & Framer Motion Animations
**Agent Prompt:**
> *"Add subtle scroll reveal animations using `framer-motion` to project cards and metric counters. Support sleek dark mode matching modern enterprise developer tools (Linear / Vercel aesthetic)."*

### Step 5: Automated Testing & Vercel Preview Pipeline
**Agent Prompt:**
> *"Write component tests in `tests/portfolio.test.ts` using Vitest and React Testing Library to verify that all project cards render correctly, filtering works, and resume download buttons trigger without errors."*
